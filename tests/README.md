Unit tests: `pytest`. Parser tests use saved Google Shopping pages in `tests/fixtures/*.html.gz`. These are not in the public repo because they contain third-party product listings. To recreate them, save the HTML of a `https://www.google.com/search?q=air+fryer&udm=28&hl=en&gl=us` page as `us_air_fryer.html.gz` (gzip), and similar pages for the other names used in `test_parser.py`. Without them, those tests are skipped.
